# IP User Roles

WordPress плагін, що дозволяє створювати користувацькі ролі з правами рівня передплатника (subscriber) і підтримує призначення кількох ролей користувачам.

[Назад](https://github.com/pekarskyi/ip-user-roles)

## Опис

IP User Roles розширює вбудовану систему керування ролями WordPress, надаючи простий, але потужний інтерфейс для створення користувацьких ролей та призначення кількох ролей користувачам. За допомогою цього плагіна адміністратори сайту можуть створювати спеціалізовані ролі для різних членів команди без необхідності встановлювати складні системи керування користувачами.

### Основні функції

* **Створення користувацьких ролей** - Створення користувацьких ролей з правами рівня передплатника
* **Призначення кількох ролей** - Можливість призначати кілька ролей одному користувачу
* **Зручний інтерфейс** - Інтуїтивно зрозумілий інтерфейс, інтегрований в адмінпанель WordPress
* **Підтримка транслітерації** - Автоматична транслітерація кириличних символів на латинські для slug-ів ролей
* **Чисте видалення** - Можливість видалити всі дані плагіна при деінсталяції

## Вимоги

* WordPress 6.0.0 або вище
* PHP 7.4 або вище

## Встановлення

1. Завантажте папку `ip-user-roles` до директорії `/wp-content/plugins/`
2. Активуйте плагін через меню 'Плагіни' в WordPress
3. Перейдіть до меню 'IP User Roles' в адмінпанелі для керування користувацькими ролями

## Використання

### Створення нової ролі

1. Перейдіть на сторінку IP User Roles в адмінпанелі
2. Натисніть "Додати нову роль"
3. Введіть назву ролі, і slug буде згенеровано автоматично (ви можете змінити його за потреби)
4. Натисніть "Створити роль"

### Редагування ролей

1. Знайдіть роль, яку хочете редагувати, у списку ролей
2. Натисніть "Редагувати" біля назви ролі
3. Оновіть дані ролі
4. Натисніть "Оновити роль"

### Видалення ролей

1. Знайдіть роль, яку хочете видалити, у списку ролей
2. Натисніть "Видалити" біля назви ролі
3. Підтвердіть видалення, коли з'явиться запит

### Призначення кількох ролей користувачу

1. Відредагуйте користувача на екрані "Користувачі" WordPress
2. Прокрутіть вниз до розділу "Множинні ролі"
3. Відзначте всі ролі, які ви хочете призначити користувачу
4. Оновіть профіль користувача

### Налаштування плагіна

1. Перейдіть до IP User Roles > Налаштування в адмінпанелі
2. Налаштуйте, чи видаляти таблиці бази даних при деінсталяції плагіна
3. Збережіть налаштування

## Часті запитання

**З: Чи можу я редагувати можливості (capabilities) користувацьких ролей?**
В: На даний момент всі користувацькі ролі успадковують можливості від ролі передплатника. Розширене керування можливостями буде додано в майбутніх версіях.

**З: Що станеться з користувачами з користувацькою роллю, якщо я видалю цю роль?**
В: Користувачам з видаленою роллю буде призначено роль за замовчуванням WordPress (зазвичай це Передплатник).

**З: Чи сумісний цей плагін з іншими плагінами керування користувачами?**
В: IP User Roles розроблений для сумісності зі стандартними функціями WordPress. Однак деякі просунуті плагіни керування користувачами можуть конфліктувати з функціональністю призначення кількох ролей.
